## 1. 项目总览

Metro Editor 是一款基于 C# WPF (.NET 8) 构建的地铁线路数据编辑器，核心能力包括：

| 能力域 | 说明 |
|--------|------|
| **编辑** | 基于 AvalonEdit 的高亮编辑器，支持 `.metro` DSL 语法 |
| **编译** | 将 `.metro` 文本编译为 `.bmetro`（GZip 压缩 JSON）或 `.json` |
| **反编译** | 将 `.bmetro`/`.json` 还原为可读的 `.metro` 源码 |
| **嵌入式导出** | 生成 `.bin`（零拷贝大端序二进制）或 C 代码（含完整解析器） |
| **路径规划** | A* 多目标加权搜索 + 物理级运行时间计算 |
| **分析** | 通勤分析、路线查询、区间运行时间计算器 |

### 技术栈

- **语言**：C# 12 / .NET 8
- **UI 框架**：WPF（XAML）
- **编辑器控件**：AvalonEdit 6.3
- **图表控件**：OxyPlot.Wpf 2.2
- **WebView**：Microsoft.Web.WebView2（地图/HTML 预览，D3.js SVG 渲染，支持线路/车站/区域）
- **序列化**：System.Text.Json + GZip 压缩
- **其他**：CsvHelper、PinYinConverterCore

## 3. 模块详解

### 3.1 编译引擎（MetroLang.Compiler）

编译引擎是项目的核心，负责将人类可读的 `.metro` DSL 源码转换为结构化的路网数据。

#### 编译流水线

```
.metro 源码
    │
    ▼
┌──────────┐     ┌───────────────┐     ┌─────────┐     ┌─────────────────┐
│  Lexer   │ ──▶ │ Preprocessor  │ ──▶ │ Parser  │ ──▶ │ CommandHandlers │
│ (词法)   │     │ (预处理)      │     │ (语法)  │     │ (命令分发)      │
└──────────┘     └───────────────┘     └─────────┘     └────────┬────────┘
                                                            │
                                                            ▼
                                                   ┌─────────────────┐
                                                   │   PostProcessor │ ──▶ Context
                                                   │   (后处理)      │
                                                   └─────────────────┘
```

#### 核心类说明

| 类 | 文件 | 职责 |
|----|------|------|
| `Lexer` | `Compiler/Lexer.cs` | 词法分析器，将源文本分解为 Token 流。使用正则表达式分词，支持注释移除、字符串保护 |
| `Preprocessor` | `Compiler/PreProcessor.cs` | 预处理器，处理 `%define`/`%undefine`/`%if`/`%else`/`%endif`/`%include`/`%import` 指令 |
| `Parser` | `Compiler/Parser.cs` | 递归下降语法分析器，提供 Token 消费、预读、错误恢复等能力 |
| `MetroCompiler` | `Compiler/MetroCompiler.cs` | 编译器入口，协调词法→预处理→语法→后处理流水线 |
| `Context` | `Compiler/Context.cs` | **编译数据上下文**，集中存储所有解析产生的中间数据，是整个编译流程的数据中枢 |
| `PostProcessor` | `Compiler/PostProcessing.cs` | 后处理器，执行语义优化：标记远期车站、去重方向、推断城市归属、展开换乘模板、执行断言等 |
| `ICommandHandler` | `Compiler/ICommandHandler.cs` | 命令处理器接口，每个顶级指令（如 `LINE_DEFINE`）实现此接口 |
| `CommandUtils` | `Compiler/CommandList.cs` | 命令注册表，将指令名映射到对应处理器 |
| `Token` / `TokenType` | `Compiler/Token.cs` / `TokenType.cs` | 词法单元及其类型枚举 |
| `SyntaxException` | `Compiler/SyntaxException.cs` | 语法异常，包含出错 Token 信息 |
| `Utils` | `Compiler/Utils.cs` | 编译器工具类，提供距离计算、线路/车站操作、通配符匹配等 |
| `Assertion` | `Compiler/Assertion.cs` | 编译时断言，支持布尔谓词和数值比较，可组合 AND/OR/NOT |

#### Context 数据结构

`Context` 是编译器的核心数据容器，分为 10 个区域：

| 区域 | 内容 | 关键属性 |
|------|------|---------|
| 1. 基础元数据 | 程序信息 | `MainCity`, `Version`, `Author`, `LanguageOrder` |
| 2. 核心路网 | 站点、线路、方向 | `Stations`, `Lines`, `Directions`, `Distances` |
| 3. 换乘与状态 | 换乘规则、车站状态 | `Transfers`, `StationStatus`, `VirtualTransfers` |
| 4. 时间参数 | 停站时间、默认参数 | `DwellTimes`, `DefaultTimes` |
| 5. 动态规则 | 发车间隔、拥挤度等 | `HeadwayRules`, `CrowdRules`, `SpeedLimits` |
| 6. 票价与优惠 | 票价配置 | `PriceConfig`, `Promotions` |
| 7. 标注与设施 | 地图标注 | `Labels`, `Facilities` |
| 8. 模板 | 换乘/线路/方向模板 | `TransferTypes`, `TransferTemplates`, `LineTemplates` |
| 9. 辅助映射 | 城市映射、条件符号 | `StationCity`, `DefinedSymbols`, `Assertions` |
| 10. 警告 | 非致命问题 | `Warnings` |

#### 后处理流程（PostProcessor.DoProcess）

```
1. MarkFutureOnlyStations    → 标记仅出现在远期方向中的车站为待开通
2. ApplyPendingTransfers     → 为待开通车站自动生成换乘规则
3. RemoveDuplicateDirections → 去重相同站点序列的冗余方向
4. RemoveSingleStationDirections → 移除站点数 < 2 的无效方向
5. InferStationCities        → 推断未显式定义城市的车站归属
6. FinalChecks               → 校验特殊线路票价、主城市、车站状态有效性
7. ExpandTransferTemplates   → 展开换乘模板为具体换乘规则
8. EvaluateAssertions        → 执行编译时断言
9. ProcessEchoMessages       → 处理 ECHO 调试输出
10. FormatStationKeys        → 统一站点键格式（添加城市后缀）
```

### 3.2 反编译器（MetroLang.Decompiler）

| 类 | 文件 | 职责 |
|----|------|------|
| `MetroDecompiler` | `Decompiler/MetroDecompiler.cs` | 将 `JsonRoot` 还原为 `.metro` 源码，支持智能反向方向识别（REV 简写）、条件输出 |

反编译流程：
1. 写入文件头（PROGRAM_DEFINE）
2. 生成站点定义（STATION_DEFINE）
3. 生成线路定义（LINE_DEFINE + 嵌套 DIRECTION_DEFINE）
4. 生成票价规则（PRICE_DEFINE）
5. 生成换乘规则（TRANSFER_DEFINE）
6. 生成运营参数（OPERATION_DEFINE，仅有自定义数据时）
7. 生成其他块（LABEL_DEFINE、FACILITY_DEFINE 等）

### 3.3 导出器（MetroLang.Exporter）

| 类 | 文件 | 职责 |
|----|------|------|
| `JsonExporter` | `Exporter/JsonExport.cs` | 将 `Context` 映射为标准 `JsonRoot`，整合坐标、换乘、城市推断 |
| `BinExport` | `Exporter/BinExport.cs` | 将路网数据序列化为嵌入式二进制 `.bin`（大端序、零拷贝）或生成 C 代码 |

**JSON 导出**：`Context → DeepClone → JsonExporter.ExportJson() → JsonRoot`

**嵌入式导出**格式特点：
- 强制大端序，支持零拷贝直接映射到 C 结构体
- 预计算区间运行时间和换乘时间，嵌入式端只需整数加法
- 支持多语言站名（主名 + 备用名分离存储）
- 生成 `metro_parser.h`、`metro_parser.c`、`metro_data.h` 三份文件

### 3.7 仿真引擎（Simulator）

Simulator 是独立的路径规划引擎，从 Android 版 MetroGraph 移植并升级为 A* 算法。

#### 目录结构

```
Simulator/
├── Algorithms/
│   ├── SimMetroGraph.cs      # 图构建 + A* 路径搜索
│   ├── SimFareCalculator.cs  # 票价计算
│   ├── SimTimeCalculator.cs  # 时间计算（换乘等待 + 行驶 + 停站）
│   ├── SimTrainTimeUtils.cs  # 物理模型（Davis阻力 + 恒功率牵引 + 辛普森积分）
│   ├── SimEdge.cs            # 图边
│   ├── SimNodeState.cs       # 节点状态（A* 优先队列元素）
│   └── SimSegment.cs         # 行程分段
├── Data/
│   ├── SimDataParser.cs      # JsonRoot → SimDataCache 解析器
│   └── SimDataCache.cs       # 数据缓存（线程安全，含所有运行时数据）
├── Models/
│   └── Models.cs             # 所有模型类（SimPathResult, SimSearchWeight 等）
└── Utils/
    ├── SimGraphKeyUtils.cs   # 方向键/节点键工具
    ├── SimStationUtils.cs    # 站点状态/换乘工具
    ├── SimPrefixFilter.cs    # 路径前缀去重过滤器
    ├── SimTrainTimeUtils.cs  # 列车运行时间物理模型
    ├── SimTextMatchUtils.cs  # 文本模糊匹配
    └── SimGraphicsViewUtils.cs # 图形视图工具
```

#### 核心类说明

| 类 | 职责 |
|----|------|
| `SimMetroGraph` | **图构建与路径搜索核心**。将路网数据构建为图结构，节点 = 方向+车站，边 = 运行边/换乘边。支持 A* 多目标搜索、随机路径、最长路径 |
| `SimFareCalculator` | 票价计算：普通里程计费 + 特殊线路票价（统一票价/区间附加费/独立分段） |
| `SimTimeCalculator` | 时间计算：行驶时间 + 换乘时间 + 停站时间 + 进出站时间 |
| `SimTrainTimeUtils` | 物理模型：Davis 阻力公式 + 恒功率牵引 + 自适应辛普森积分 |
| `SimDataCache` | 数据缓存：线程安全的 ConcurrentDictionary，存储所有运行时数据 |
| `SimDataParser` | 数据解析：将 JsonRoot 转换为 SimDataCache |
| `SimSearchWeight` | 搜索权重：距离、换乘、票价、时间、站点数、拥挤度的加权组合 |

#### A* 路径搜索流程

```
FindTransferPath(start, end, weight, travelTimeMillis)
    │
    ├── Task 1: FindTransferPathInternal(weight, excludeSpecial=true)
    ├── Task 2: FindTransferPathInternal(weight, excludeSpecial=false)
    └── Task 3: FindTransferPathInternal(shortestWeight, excludeSpecial=true)
         │
         ▼
    A* 搜索：
    1. 初始化起点节点（所有经过起点站的方向）
    2. 优先队列按 g+h 排序（h = 地理距离/最高速度）
    3. 遍历邻接边：
       - 同方向边：距离权重 + 时间权重（物理模型）+ 站点权重 + 拥挤度权重
       - 换乘边：换乘权重 + 时间权重（步行 + 候车）
    4. 到达终点节点 → 回溯路径
         │
         ▼
    后处理：
    - 前缀去重（FilterUniquePrefixBlocks）
    - 票价计算（SimFareCalculator）
    - 择优返回（综合代价最小）
```

## 4. 核心数据流

### 4.1 编译流程

```
用户在编辑器中编写 .metro 源码
         │
         ▼
MetroCompiler.Parse(sourceText, baseDir)
    │
    ├── Lexer.Tokenize(sourceText)         → List<Token>
    │     └── RemoveComments()             → 移除注释（保留行号）
    │     └── 正则分词                      → Number/String/Id/Symbol/Newline
    │
    ├── Preprocessor.Process(tokens)        → List<Token>（过滤后）
    │     ├── %define / %undefine           → 条件符号管理
    │     ├── %if / %else / %endif          → 条件编译
    │     ├── %include "path"               → 递归嵌入外部文件
    │     └── %import "path" AS STATIONS   → 从 CSV 导入站点
    │
    ├── Parser + CommandHandlers            → Context
    │     └── 每个顶级指令由对应 ICommandHandler 处理
    │         例：LINE_DEFINE → LineDefine.Handle()
    │              STATION_DEFINE → StationDefine.Handle()
    │
    └── PostProcessor.DoProcess()           → Context（优化后）
          ├── 标记远期车站
          ├── 去重方向
          ├── 推断城市归属
          ├── 展开换乘模板
          └── 执行断言
```

### 4.2 导出流程

```
Context（编译中间态）
    │
    ├── ExportJson()                        → JsonRoot
    │     └── JsonExporter.ExportJson()
    │           ├── BuildStations()         → 站点坐标 + 线路归属
    │           ├── BuildLines()            → 线路 + 方向 + 距离
    │           ├── BuildTransfers()        → 换乘规则
    │           ├── BuildPrice()            → 票价配置
    │           └── BuildOperationParams()  → 运营参数
    │
    ├── JsonSerializer.Serialize(JsonRoot)  → JSON 字符串
    │
    ├── GZip 压缩                            → .bmetro 文件
    │
    └── BinExport.Export()                  → .bin / .c / .h 文件
          ├── 大端序二进制布局
          ├── 预计算区间运行时间
          └── 生成 C 语言解析器代码
```

### 4.3 路径规划流程

```
JsonRoot（.bmetro 解压后 / .json 读取）
    │
    ├── SimDataParser.Parse(JsonRoot)       → SimDataCache
    │     ├── 解析站点坐标、状态、换乘规则
    │     ├── 解析线路属性、方向、距离
    │     ├── 解析票价规则
    │     └── 解析发车间隔、拥挤度等动态规则
    │
    ├── new SimMetroGraph(SimDataCache)     → 构建图结构
    │     ├── ParseLines()                  → 方向邻接表 + 同线路边
    │     ├── ParseStations()               → 换乘边
    │     └── BuildDirDisplayNames()        → 主支线映射 + 显示名
    │
    └── FindTransferPath(start, end, weight)
          ├── 并行 3 路 A* 搜索
          ├── 前缀去重
          ├── 票价计算（SimFareCalculator）
          └── 返回 SimPathResult
                ├── Path: List<string>      → 节点列表
                ├── Transfers: int           → 换乘次数
                ├── Cost: double             → 综合代价
                ├── TotalMoney: double       → 总票价
                └── SpecialMoney: double     → 特殊票价
```

### 4.4 反编译流程

```
.bmetro 文件
    │
    ├── GZip 解压                            → JSON 字符串
    │
    ├── JsonSerializer.Deserialize<JsonRoot>()→ JsonRoot
    │
    └── MetroDecompiler.Decompile()
          ├── GenerateProgramDefine()        → PROGRAM_DEFINE 块
          ├── GenerateStations()             → STATION_DEFINE 块
          ├── GenerateLines()                → LINE_DEFINE + DIRECTION_DEFINE 块
          │     └── 智能反向方向识别（REV 简写）
          ├── GeneratePrice()                → PRICE_DEFINE 块
          ├── GenerateTransfers()            → TRANSFER_DEFINE 块
          └── GenerateOperation()            → OPERATION_DEFINE 块（条件输出）
                → .metro 源码字符串
```

## 5. 关键算法说明

### 5.1 A* 路径搜索

- **启发式函数**：地理距离 / 全局最高速度 → 最小行驶时间下界
- **边代价**：距离权重 × 距离 + 时间权重 × 行驶时间/60 + 站点权重 + 拥挤度权重 × (拥挤度-1)
- **换乘边代价**：换乘权重 + 时间权重 × (步行换乘时间 + 候车时间) / 60
- **并行搜索**：3 路并行（排除/包含特殊线路 + 最短距离基准），择优返回

### 5.2 物理级运行时间（SimTrainTimeUtils）

基于 Davis 阻力公式和恒功率牵引模型：

```
阻力: R = (a + b·v + c·v²) × W    [Davis 公式]
牵引: F = P / v                    [恒功率]
加速: a = (F - R) / m

运行时间 = ∫(m·v / (P - v·R(v))) dv    [自适应辛普森积分]
```

- 支持 A/B/C/L/D 型车的物理参数
- 短区间（≤1.5km）精确计算，长区间使用 ΔT 缓存加速
- 考虑加速-巡航-制动三阶段或加速-制动两阶段（短区间）

### 5.3 换乘等待时间模型

```
T_wait = T_headway / 2 + T_board + (C - 1) × T_headway

其中：
  T_headway = 发车间隔（秒）
  T_board   = 上车时间（秒，默认 3）
  C         = 拥挤度因子（>1 时需要等待多趟车）
```

### 5.4 票价计算

```
普通票价 = 阶梯区间查表 → 线性扩展（超出阈值按公里加收）

特殊线路票价:
  - 统一票价（All）: 固定金额
  - 区间附加费（Surcharge）: 普通票价 + 指定区间附加费
  - 独立分段计价（DefaultFare + Segments）: 自定义阶梯票价
```

### 5.5 站间距自动计算

使用 Catmull-Rom 样条曲线 + Haversine 公式：
1. 取相邻 4 个站点坐标作为控制点
2. 通过样条参数方程生成 40 个采样点
3. 累加相邻采样点的球面距离
4. 环线方向额外计算首尾闭合距离

  - `TransferWeight`：换乘惩罚
  - `MoneyWeight`：票价权重
  - `TimeWeight`：时间权重（秒/60）
  - `StationWeight`：站点数权重
  - `CrowdWeight`：拥挤度权重
